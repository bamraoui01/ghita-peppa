# Ghita et Peppa — La fête des flaques

Petit jeu de fan non officiel en français. Peppa Pig et ses personnages appartiennent à leurs ayants droit.

Ouvrir `index.html` dans un navigateur, ou servir ce dossier avec un serveur web statique. Aucune installation, dépendance, publicité, requête externe ou collecte de données.

## Jouer

Cliquer sur **Jouer avec Peppa**, puis **Sauter !**. Le clavier fonctionne avec Espace ou Flèche haut. Chaque saut rapporte une étoile ; un ami apparaît toutes les deux étoiles. Six étoiles terminent la partie. Le bouton **Rejouer** relance une partie. Le son est facultatif et désactivé au départ. Le jeu respecte la préférence de réduction des animations.

## Publier sur GitHub Pages

Créer un dépôt public `ghita-peppa`, y ajouter `index.html`, `game.js`, `README.md` et `.nojekyll` à la racine. Dans Settings → Pages, choisir **Deploy from a branch**, branche **main**, dossier **/(root)**, puis Save. GitHub fournit ensuite le lien public.
